# The variety ledger

Every video made: premise, format, cast, sets, outcome. A new script that repeats an earlier outcome with the same cast
in the same situation is rewritten before anything is built (YouTube's "inauthentic content" rule names "templated
storylines" and "the same situation over and over with the same outcome").
