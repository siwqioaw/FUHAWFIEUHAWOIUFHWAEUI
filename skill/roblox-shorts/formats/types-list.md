# Types list: "When [moment]" / "Types of [group]" (family C, music only)

**Use when** the concept is one shared moment and how different people react (when the bell rings, when the teacher
says "pick a partner").

**Length** about 11 s; no voice; 30 fps. A header for the moment from frame 0, then 3-4 types, each one shot of
exactly four beats with a coloured label (`label` style: `"{blue:The try-hard}"`), "Me:" last or a bookend repeating
the first shot with a new face. One track, cut on the downbeat.

## Rubric

A header on frame 0; each type readable from its pose and face alone; labels in a colour per type; "Me:" lands the
joke.
